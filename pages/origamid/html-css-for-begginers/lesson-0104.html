O browser (navegador) é o responsável programa que vai interpretar e executar os códigos das páginas web. Existem vários navegadores diferentes no mercado, como:

  • Google Chrome
  • Firefox
  • Microsoft Edge
  • Opera
  • Brave

O navegadores podem ser executados em diferentes tipos de dispositivos, que vão desde um desktop, notebook, celular, televisão, ou até geladeiras.

Tem um site chamado Can I Use onde eu posso ver informações sobre as tecnologias utilizadas em diferentes navegadores e o quanto elas são compatíveis com cada um. Então antes de deu aplicar algo no meu site eu posso ver com quais navegadores aquilo é compatível e se fica viável pra mim, dependendo do meu objetivo.
