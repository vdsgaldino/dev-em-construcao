O que são as tags em HTML?

As tags (etiquetas) são utilizadas na HTML como forma de marcação para o conteúdo, dando um determinado significado pra ele.

Um exemplo de tag seria a tag p:

<p> texto de parágrafo </p>
Essa tag indica que aquele texto é um parágrafo.

Geralmente as tags tem uma abertura e um fechamento. No exemplo anterior a abertura seria o <p> e o fechamento seria o </p>, mas existem algumas tags que só tem abertura e não precisam ser fechadas, como por exemplo a tag <br>.

O que são os atributos de uma tag?

Os atributos são características daquela tag que podemos modificar passando alguns valores pra eles. Eles são informados dentro da tag e alguns desses atributos são obrigatórios e outros opcionais, dependendo da tag utilizada.

Um exemplo de atributos em uma tag seria a tag a: 

<a href="www.google.com"> Conteudo </a>
Nesse caso o atribuito utilizado é o href e o valor atribuido para ele seria o "www.google.com". Fazendo uma explicação bem breve, esse atributo é o responsável por indicar o destino de um link, nesse exemplo o destino seria o site do Google.

Qual o motivo de utilizarmos essas tags?

As tags são importantes pois:

  1. Servem para incluir conteúdo dentro do nosso documento HTML.
  2. Aplicam a semântica no código, ou seja, dá um significado para cada coisa que foi escrita ali.
  3. São usadas para criar interações com a parte e estilos (CSS) e com a parte lógica e funcional (JavaScript).

Dicas que foram passadas nessa aula

  • Uma boa prática é sempre escrever os nomes dos arquivos e pastas do projeto com letras minúsculas.
  • As tags não são casesensitives (sensíveis a letras maiúsuculas ou minúsuculas), então eu posso escrever tanto tudo minúsculo <br> quanto <BR> que da no mesmo. Porém, por padrão, é melhor escrever sempre em minúsuculas.
