Nessa aula vão ser apresentados alguns atalhos mais comuns utilizados no VS Code que ajudam a deixar o processo de desenvolvimento mais ágil.

Aproveitando o embalo pra fazer uma retratação aqui, alguns recursos que já to utilizando nessas páginas iniciais só vão ser mostrados em aulas futuras, mas como eu já conheço um pouco eu tô utilizando. Um exemplo são essa estrutura de listas que vou usar pra descrever os atalhos e algumas coisas mais básicas de CSS (usei só pra não deixar tão feio assim e foi pouca coisa, só pra deixar as imagens com um tamanho mais aceitável e não ficarem gigantes como estavam).

Voltando, os atalhos mostrados nessa aula foram:

  • CTRL + C (Copiar uma seleção)
  • CTRL + X (Recorta uma seleção)
  • CTRL + V (Cola aquilo que foi copiado)
  • CTRL + Z (Desfaz a ultima alteração)
  • CTRL + SHIFT + Z ou CTRL + Y (Retorna o que eu acabei de desfazer usando o Ctrl + Z)
  • pressionar ALT + seta (Posso usar pra mover uma linha pra cima ou pra baixo)
  • CTRL + ; (Criar um comentário no código)
  • CTRL + B (Minima o explorador de arquivos lateral)

Como criar atalhos personalizados?

Para criar atalhos personalizados posso pressionar CTRL + SHIFT + P e na barra de pesquisa procurar por "Keyboard Shortcuts". Nessa parte eu consigo modificar os atalhos e personalizar de acordo com as minhas necessidades.
