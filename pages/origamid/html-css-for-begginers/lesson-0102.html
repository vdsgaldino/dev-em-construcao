Nessa aula é explicado um pouco do que é cada uma dessas tecnologias de desenvolvimento Front-End.

HyperText Markup Language (HTML)

HTML é a linguagem de marcação utilizada para construir toda a parte de conteúdo do site. Isso inclui: títulos, parágrafos, imagens, vídeos, listas, etc.

Os arquivos dessa linguagem possuem a extensão .html.

Exemplo de código HTML 

                
                    <p>Olá Mundo</p>

Cascading Style Sheets (CSS)

As CSS são a linguagem utilizadas para realizar a parte do estilo da página, como cores, alinhamento, posicionamento, tamanhos, sombras, etc.

Os arquivos CSS possuem a extensão .css.

Exemplo de código CSS 

            
                <style>
                    p {
                        color: blue;
                    }
                </style>

JavaScript

O JavaScript é a linguagem de programação. E ela quem faz a parte das funções e automações dentro do site. Também altera os componentes dentro do documento HTML e também busca informações de outros sites.

Os arquivos JavaScript possuem a extensão .js.

Exemplo de código JavaScript 

            
                <script>
                    function mudar() {
                        texto.style.color = 'red';
                    }
                    texto.addEventListener('click',)
                    </script>
