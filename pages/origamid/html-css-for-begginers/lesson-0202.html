Nessa aula foram apresentadas algumas das tags mais comuns. As tags apresentadas foram

  • p: marcar parágrafos
  • h1, h2, h3, h4, h5 e h6: marcar títulos
  • a: marcar links

A tag h1 ao h6 é usada pra títulos de acordo com a sua importância dentro da página. Então o título que foi marcado com a tag de h1 vai ser o título principal, o mais importante. Já um título marcado com a tag h2 será o segundo mais importante ali, o outro com h3 seria o terceiro mais importante...e assim vai.
Vou colocar um exemplo usando essas tags aqui embaixo.

Pra fazer essa linha horizontal eu usei a tag <hr>, que é uma tag que não precisa de fechamento, só abertura.
