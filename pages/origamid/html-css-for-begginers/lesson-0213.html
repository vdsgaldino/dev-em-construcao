Fluxo do Layout

O fluxo do layout funciona de acordo com o modo de escrita definido. Então a ordem vai ser geralmente de cima pra baixo e da esquerda para direita. Os elementos de mesma linha (inline) tendem a se comportar se posicionando ao lado, enquanto os elementos de bloco (block) sempre saltam a linha. Por exemplo:

"texto puro sem tag" "novo texto span "novo link teste"

Teste de parágrafo

Eu escrevi acima um texto puro sem adicionar nenhuma tag nele, logo abaixo no código eu inclui um texto com a tag span, que é uma tag genérica que usamos quando queremos aplicar alguma alteração em um item muito especifico e por fim coloquei um link. Por terem comportamento de display inline ele se posicionam por padrão na mesma linha. Já abaixo deles eu adicionei um parágrafo e esse parágrafo não continuou na mesma linha pois o comportamento dele é display block, então ele salta a linha e aparece abaixo do primeiro texto.

Display inline e block

Display Inline

Respeita o fluxo da escrita sem iniciar uma nova linha. Pra ele eu não consigo definir valores de largura (width), altura (height), margem (margin)...etc. Esse é o estilo padrão dos elementos.

Display Block

Ele inicia uma nova linha e não permite que outros elementos sejam posicionados em sua linha. Ele aceita todas as propriedades do box model e é o estilo inicial de alguns elementos como h1, p, div e etc.

Display None

Aqui ele remove a visualização do elemento completamente da tela. Deixa ele invisível.

Display Inline-block

No inline-block ele continua sendo um elemento inline mas passa a poder receber as propriedades do box model (width, height...)
